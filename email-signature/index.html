“Copy signature” puts the formatted version on the clipboard — paste straight into your mail client’s signature editor.

Installing

  1. Superhuman — Settings → Signature, then paste the formatted copy.
  2. Outlook (web / new Outlook) — Settings → Mail → Compose and reply → Email signature, then paste.
  3. Outlook (classic desktop) — File → Options → Mail → Signatures, then paste.
  4. Gmail — Settings → See all settings → Signature, then paste.
  5. Apple Mail — Settings → Signatures; uncheck “Always match my default message font” before pasting.

If a client strips the formatting, open signature.html in a browser, select all, copy, and paste that instead.
